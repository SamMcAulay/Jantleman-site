COMMAND GUIDE

Complete reference for all Jantleman slash commands. All commands use Discord's / slash command system.

⭐ Reputation 🔨 Moderation 🔔 Watchlist ⚙️ Settings ℹ️ Info
How it works: Jantleman monitors your forum channels for new posts. When someone creates a thread, the bot automatically looks up their reputation history and posts a summary embed — helping your community make informed decisions before engaging.
⭐ Reputation
/review Leave a star rating and comment for a user ▼

Submit a reputation review for another member. Reviews are permanent and visible to anyone who looks up that user. Each review includes a star rating (1–5), an optional comment, and optional proof (screenshot URL).

Options
user Required The Discord member to review.
stars Required Rating from 1 to 5.
comment Optional A short description of your experience.
proof Optional URL to a screenshot or evidence of the transaction.
Example
/review user:@Username stars:5 comment:Fast and reliable seller. proof:https://i.imgur.com/...
👤 Any member
/profile View a user's reputation score and review history ▼

Displays a member's full reputation card — their average star rating, total number of reviews, and a list of recent reviews with comments and proof links.

Options
user Optional The member to look up. Defaults to yourself.
Example
/profile user:@Username
👤 Any member
/leaderboard Show the top-rated members in this server ▼

Displays the top 10 members ranked by average star rating (minimum 3 reviews required to appear).

👤 Any member
🔨 Moderation
/blacklist add Prevent a user from posting in monitored channels ▼

Adds a member to the blacklist. Any thread they create in a monitored forum channel will be automatically deleted and they'll receive a DM explaining why. The blacklist is global across all monitored channels in your server.

Options
user Required The member to blacklist.
Example
/blacklist add user:@Username
🔧 Manage Server
/blacklist remove Remove a user from the blacklist ▼

Restores posting access for a previously blacklisted member.

Options
user Required The member to unblacklist.
🔧 Manage Server
/limit set Set a posting cooldown for a specific user ▼

Restricts a member to posting once per N hours in monitored channels. If they try to post before the cooldown expires, their thread is deleted and they receive a DM with the remaining wait time.

Options
user Required The member to apply a limit to.
hours Required Number of hours between allowed posts (minimum 1).
Example
/limit set user:@Username hours:24
🔧 Manage Server
/limit remove Remove a posting cooldown from a user ▼

Removes any active posting limit for the specified member, restoring normal posting access.

Options
user Required The member to remove the limit from.
🔧 Manage Server
/namehistory View a member's recent display name changes ▼

Shows the last 10 display name changes for a member, with timestamps. Useful for identifying users who change their name frequently to avoid recognition. Only tracked if identity tracking is enabled in your server settings.

Options
user Required The member to look up.
🔧 Manage Server
🔔 Watchlist
The watchlist lets you track keywords. When a new thread title or body matches one of your keywords, you'll receive a DM alert linking to the thread.
/watchlist add Add a keyword to your personal watchlist ▼

Adds a keyword or phrase to your watchlist. You'll be DMed whenever a new thread in a monitored channel contains this word. Matching is case-insensitive.

Options
keyword Required The keyword or phrase to watch for.
Example
/watchlist add keyword:nvidia rtx 4090
👤 Any member
/watchlist remove Remove a keyword from your watchlist ▼

Stops alerting you for the specified keyword.

Options
keyword Required The keyword to remove.
👤 Any member
/watchlist list View your active watchlist keywords ▼

Shows all keywords currently on your personal watchlist.

👤 Any member
⚙️ Settings
/monitor add Add a forum channel for Jantleman to monitor ▼

Tells the bot to watch a specific forum channel. When a new thread is created there, the bot will automatically post a reputation embed for the thread owner.

Options
channel Required The forum channel to monitor. Must be a Forum Channel type.
Example
/monitor add channel:#selling
🔧 Manage Server
/monitor remove Stop monitoring a forum channel ▼

Removes a channel from the monitored list. The bot will no longer post reputation embeds for new threads in that channel.

Options
channel Required The forum channel to stop monitoring.
🔧 Manage Server
/settings tracking Toggle identity change tracking on or off ▼

Controls whether the bot tracks display name changes for members. When enabled, users who change their name frequently will trigger a warning in the reputation embed. Useful for detecting scammers who rename to avoid detection.

Options
enabled Required true to enable, false to disable.
🔧 Manage Server
/settings proof Configure the proof requirement for reviews ▼

Sets how proof (screenshot URL) is handled when members submit reviews.

Options
mode Required required — proof URL must be provided · optional — proof is accepted but not enforced · off — proof field is hidden.
🔧 Manage Server
